# Terminology Map — critical-hit-chance-damage-bonus-transition

How the article defines each key term (EN → ZH).

| Term (EN)             | Term (ZH)    | Definition in article                                                                                    |
| --------------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| Base Crit Chance      | 基础暴击几率 | Starting crit probability; weapon base for attacks, skill base for spells                                |
| Flat Crit Chance      | 固定暴击几率 | Additive points added to base before Increased                                                           |
| Increased Crit Chance | 增加暴击几率 | All +% crit chance modifiers summed into one multiplier                                                  |
| Critical Damage Bonus | 暴击伤害加成 | Extra damage on a crit; all sources add together (current PoE2 name; successor to old "Crit Multiplier") |
| Crit Check            | 暴击判定     | Single random roll vs Crit Chance per Hit                                                                |
| Hit Chance            | 命中率       | Result of Accuracy vs Evasion; gates whether a crit can occur                                            |
| Transition            | 转型         | Moving a build from non-crit to crit-focused scaling                                                     |

Avoided term: "Critical Strike Multiplier" (legacy PoE1 name) — replaced throughout with "Critical Damage Bonus".
