# Version Diff — essence-crafting-guaranteed-modifiers

What changed vs older guides / legacy info to avoid.

## Current (0.5.0+, patch 0.5.4)

- **One-essence rule:** a single item can carry only ONE essence-crafted modifier at a time.
- Essence is now a starter anchor for a craft, finished with other currency/omens — not the whole craft.
- Perfect Essence: removes a mod, then adds a special exclusive mod (Rare target).
- Corrupted essences obtained conditionally via Vaal Orb on an imprisoned Greater-essence monster.

## Legacy (pre-0.5.0) — DO NOT repeat

- Stacking two or more essence mods on a single base. This is no longer possible and must be flagged as outdated in the `version-conflicts` section.
- Any guide implying essence crafts a full item by itself.

## Avoided fabrications

- No exact drop rates, prices, or Perfect modifier numbers stated. These are version-dependent and marked pending PC verification.
