# Community Questions — item-modifiers-item-level-prefix-suffix

Real player confusions this article answers (paraphrased from common community discussion; cited where a public source exists).

1. **"Holding Alt doesn't show tiers / I can't see modifier strength."**
   - Answer: Advanced modifier view (PC: hold Alt; controller: toggle) is required to reveal tiers.
   - Source: Alphagamer video timestamp 0:00 / poe2wiki Mod.

2. **"Why is my item level low but I still can't get good rolls?" (iLvl vs req level mix-up)**
   - Answer: Only the item's own Item Level gates modifier tiers; character level does not.
   - Source: Maxroll crafting guide.

3. **"Why does currency say 'no available modifier'?"**
   - Answer: The item's level/base pool has nothing valid left for that currency.
   - Source: derived from poe2wiki Mod mechanic.

4. **"Same modifier name, different value on two items — bug?"**
   - Answer: Roll range depends on base type and iLvl.
   - Source: poe2wiki Mod.

5. **"Does a Divine Orb upgrade tier?"**
   - Answer: No; it only rerolls values within the existing tier.
   - Source: Maxroll.

6. **"Are all prefixes offensive and all suffixes defensive?"**
   - Answer: Convention, not law — exceptions exist.
   - Source: poe2wiki Mod, Maxroll.
