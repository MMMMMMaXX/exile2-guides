# Community Questions

Real player questions this article answers (paraphrased from community guides/forums).

1. **"Where do I put the .build file?"** — Windows `Documents\My Games\Path of Exile 2\BuildPlanner`. Source: games.gg import guide.
2. **"Why isn't my build showing in the dropdown?"** — Wrong folder, wrong extension, or game not restarted. Source: games.gg / Ydoc video.
3. **"Is a .build file a virus / can it run code?"** — No, it is plain data. Source: developer docs (file format).
4. **"Does it work on Mac or console?"** — Mac unverified (0.5.4); consoles unsupported (0.5.0). Source: games.gg.
5. **"Does the planner calculate DPS?"** — No. Source: developer docs / games.gg.
6. **"How do I pick the right level/budget variant?"** — Match the file's stated level/gear range to your character. No single public source; derived from in-game stage behavior described by Ydoc.
