# Conflict Log — omen-crafting-prefix-suffix-control

Conflicting community info encountered and how it was resolved.

1. **"Only one Omen per craft" vs "stack multiple Omens".**
   - Conflict: some older/utility-Omen text says only one Omen can trigger; crafting guides describe stacking several.
   - Resolution: Distinguish combat/utility Omens (often one per instance) from crafting Omens (multiple can be active and combine per their tooltips). The guide covers crafting Omens and states combination is per-Omen, sourced from Mobalytics.

2. **Omen source: Ritual only vs Currency Exchange.**
   - Conflict: one source implied Omens drop only from Ritual; another (and the brief) includes Alva's Currency Exchange.
   - Resolution: Include both Ritual (Tribute) and Currency Exchange, matching Mobalytics and IGN.

3. **Exact Omen list length.**
   - Conflict: community counts vary (e.g., "17 types", growing sets).
   - Resolution: Do not assert a total count; present an example subset and direct readers to the in-game tooltip and poe2wiki, flagged pending PC verification.

4. **"Official" wiki labeling.**
   - Conflict: brief calls poe2wiki the "official" Omen page, but it is community-run.
   - Resolution: Keep the real URL but set sourceType to "community" for accuracy; no fabricated official GGG URL.
