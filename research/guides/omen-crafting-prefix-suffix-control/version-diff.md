# Version Diff — omen-crafting-prefix-suffix-control

What changed versus older guides / legacy info to avoid.

- **Naming scheme is stable but the list grows.** The Sinistral (prefix) / Dextral (suffix) + currency-family naming has been consistent in recent patches, but the _full set_ of Omens has expanded. Legacy 2025 lists that enumerate only a handful of Omens are incomplete and should be treated as outdated (see `version-conflicts`).
- **New Omen families added over time.** Families such as Crystallisation (Essence), Homogenising, and Whittling appeared after early access launch. Guides written before these exist will miss them.
- **Stacking behavior is per-Omen.** Older advice sometimes implied a fixed global stacking order; current guidance is that combination is defined by each specific Omen's tooltip. Avoid stating a universal order.
- **Client version for this guide:** 0.5.4. All exact numbers (drop level, stack size, prices) are avoided and flagged pending PC verification rather than copied from older patch data.
- **Avoid:** copying 2025 omen tables verbatim; asserting fixed stack order; claiming Omens work on uniques the same way as rares.
