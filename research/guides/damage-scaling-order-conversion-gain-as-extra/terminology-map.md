# Terminology Map — damage-scaling-order-conversion-gain-as-extra

| Term | How the article defines it |
|------|----------------------------|
| Base Damage | The skill's innate damage of its inherent type before any modifiers. |
| Added Damage | Flat "Adds X to Y damage" numbers, summed and added to the base. |
| Increased | Percentage bonuses additive within the same damage category, applied once. |
| More / Less | Percentage multipliers that always multiply the running total (More up, Less down). |
| Conversion | Changes a percentage of one damage type into another, removing the converted portion. |
| Gain as Extra | "Gain X% of Y as Extra Z" adds damage of type Z while keeping the original Y. |
| Crit (critical hit) | A multiplier applied after scaling, on the already-augmented total. |
| Damage Taken | An incoming-damage modifier on the target; not part of your outgoing scaling. |

Localization note: EN file uses English terms; ZH file uses Simplified Chinese equivalents (基础伤害, 附加伤害, 增大, 更多/更少, 转化, 额外获得, 暴击, 承受伤害).
