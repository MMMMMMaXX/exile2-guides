# Terminology Map — power-frenzy-endurance-charges

| Term | Definition used in article |
|------|----------------------------|
| Charge | A temporary, stackable combat resource (Power/Frenzy/Endurance) you generate and then spend. |
| Power Charge | Intelligence-linked (blue) charge; common consumers: Falling Thunder, Charge Infusion. |
| Frenzy Charge | Dexterity-linked (green) charge; common consumers: Barrage, Amazon Infuse Weapon. |
| Endurance Charge | Strength-linked (red/orange) charge; common consumers: Infernal Cry, Rally, Seismic Cry. |
| Generation | How you acquire charges (skills, supports, passives, items). |
| Consumption | Spending a charge via a skill/passive that explicitly interacts with it. |
| Maximum Charges | Per-type cap you can hold at once. |
| Charge Duration | How long a held charge persists before expiring. |
| Generation amount | How many charges a single event grants. |
| Combat Frenzy | Setup that grants a Frenzy Charge on Freeze/Electrocute/Pin (short cooldown). |
| Resonance | Keystone that redirects which charge type you generate. |
| Charge Infusion | Persistent buff granting effects from active charges, consuming them on a timer. |

All terms are defined in EN and ZH article bodies (overview/quick-answer sections).
