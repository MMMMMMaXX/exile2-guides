# Version Diff

What changed vs older guides / legacy info to avoid.

- **Placement target**: Legacy guides say right-click the tablet onto the tower node. Current 0.5.4 flow: clear the Tower, then place tablets from the Atlas screen. (Outdated flag in `version-conflicts` section.)
- **Effect delivery**: Legacy "walk into the radius aura" no longer exists. Current: tablet applies to all maps in the Tower radius automatically from the Atlas screen.
- **Map Device role**: Legacy guides blurred tablet vs Waystone. Current: Map Device runs the Waystone map; tablets live in the Tower.
- **Charges**: Legacy implied unlimited-while-in-tower. Current: tablet is consumed per map run; remaining uses shown on the tablet. Exact charge count pending in-game verification.
- **Wiki note**: poe2wiki's Tablet page currently documents the 0.3.1+ "place into Map Device" model, which differs from the brief's 0.5.4 Atlas-screen model. Treated as a known conflict (see conflict-log); article follows the brief.

Avoid repeating any tutorial that shows clicking a tablet in inventory or entering a radius aura.
