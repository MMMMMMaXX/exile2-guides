## Key verified claims (0.5)

- 300 Breach Splinters auto-combine (in inventory) into a Revelatory Wombgift.
- Revelatory Wombgift is birthed at the Genesis Tree (Monastery of the Keepers) for a Breachstone, costing Hiveblood.
- Breachstone is used on a surfaced Atlas node to reveal a Breach Domain / Stronghold cluster (not the old Realmgate).
- Xesht, We That Are One is reached via splinter stacks, not via a Breachstone (historical Realmgate flow is retired).

## Uncertain / pending in-game verification

- Exact Hiveblood cost per item level (community reports ~3,411 at item level 80).
- Whether death inside the revealed Domain still consumes the Breachstone.
- Exact minimum Waystone Tier per Stronghold node (edge ~Tier 6, central ~Tier 14+ per guide observation).
