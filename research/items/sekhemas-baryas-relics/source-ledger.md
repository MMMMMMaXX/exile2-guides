## Notes

- Barya family: Balbala's (quest, returned on fail), Djinn (drop/trade, iLvl → floors 1–4), Test of Strength/Will/Cunning/Time (save run, continue floor).
- Relic Altar: 18 slots, 12 unlock by floor completion; Relics must be placed before the run starts and are locked once it begins.
- Unique Relics drop from Zarokh; applying one converts the run to a challenge run and the relic is consumed.
- Area-level-to-floor mapping: 22 / 45+ / 60+ / 75+ → 1 / 2 / 3 / 4 floors.
- Uncertain 0.5 mechanics are flagged "pending in-game verification" (verificationStatus pending-pc, verifiedClientVersion 0.5.4).
