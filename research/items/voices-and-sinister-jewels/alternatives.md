# Alternatives — Voices and Sinister Jewel Sockets

- Tree Jewel Sockets: allocate and path to them; costs passive points but accepts any jewel including radius jewels. Use when you already path nearby.
- From Nothing: remote Keystone allocation (different mechanic, not jewel slots).
- Controlled Metamorphosis: ring-shaped remote allocation (different mechanic).
- The Adorned: amplifies corrupted Magic jewels (different mechanic, tree socket).
- Megalomaniac: allocates Random Notables (tree socket, different).
- Basic / Rare jewels in tree sockets: cheaper but require pathing.

Pick the alternative that matches the need: tree sockets for radius/weekstone builds, Voices for free off-tree jewel slots. Voices is the only source of Sinister (portrait-side) sockets.
