# Current vs Legacy — Voices and Sinister Jewel Sockets

Historical issues are separated from current rules (plan §16).

## Voices
- Current (0.5.4): see current-version.md. Sapphire Unique that allocates 2/3/4 Sinister Jewel Sockets, excludes Unique jewels, no radius, Corrupted, Simulacrum drop.
- Legacy: Voices did not exist before 0.5.0. Any guide referencing "Sinister Jewel Sockets" prior to 0.5.0 refers to a different/non-existent state and must not be cited as current.

## Related systems
- Legacy (pre-0.2 passive-tree rebuild): some tree Jewel Sockets were removed; /reclaimjewels historic recovery. Voices sockets are NOT tree sockets, so this does not affect them — noted to avoid confusion.

Never present a legacy value as the current 0.5.4 value.
