# Build Usage — Voices and Sinister Jewel Sockets

Personas (see published build-usage section):

- Jewel-scaling attribute stacker — wants 3-4 Sinister Sockets for attribute/crit/life jewels without tree travel.
- Off-tree enabler — builds that cannot path to tree sockets use Voices for free slot access.
- Endgame min-max — 4-socket Voices for maximum jewel investment (premium).
- Budget enabler — 2/3-socket Voices as a stepping stone.

Decision rule: equip Voices when the number of quality jewels you can slot (2/3/4) beats the passive points you would otherwise spend reaching tree sockets. Unique jewels cannot be used, so plan around Magic/Rare jewels only.
