## Key verified claims (0.5)
- 300 Simulacrum Splinters auto-combine into an itemised Simulacrum (a currency item, not a Waystone).
- Applied to an Atlas map node at 100%+ Deliriousness, inside the Delirium fog -> Simulacrum of Delusion.
- Current encounter is 7 waves; Deliriousness scales 100% (wave 1) to 200% (wave 7).
- Between waves you pick one shard effect (Escalating Threats / Apex Predators / Pure Emotions).
- Old 15-wave / Realmgate version is historical (pre-0.5).

## Uncertain / pending in-game verification
- Whether the itemised Simulacrum is refunded on death (treated as consumed on apply).
- Exact Delirium Atlas passive requirement for splinter drops ("Is This About Me or You?" per guide observation).
- Whether the underlying Waystone mods are retained when the node is transformed.
