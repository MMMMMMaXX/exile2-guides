# Current vs Legacy — Kitoko's Current

Checked date: 2026-08-03

## Summary

Kitoko's Current has been in the game since 0.1.0 with the SAME core mod line. There is no functionally different "old version" that changed the Electrocution redirect or the speed-penalty range. The only thing that varies between dropped copies is the rolled numbers (Energy Shield, Dexterity, and the 10-15% speed penalty).

## Current (0.5.4, Early Access)

- Base Energy Shield: 29-34
- (30-50)% increased Energy Shield
- +(10-20) to Dexterity
- (10-15)% reduced Attack and Cast Speed
- Lightning damage from Hits Contributes to Electrocution Buildup
- Requirements: Level 26, 34 Intelligence
- Electrocution is a live ailment vs the current Elemental Ailment Threshold system.

## Legacy / historical

- 0.1.0: item introduced with the same mod line.
- No patch note changed the Electrocution redirect or the 10-15% reduced speed range.
- "Legacy" therefore means an older dropped roll range, not a different item.

## Divine Orb behavior

- A Divine Orb re-rolls the existing numeric ranges (ES, Dexterity, speed penalty).
- It CANNOT add or remove the Electrocution mod.
- Because the mod line never changed, a Divine never converts an old item into a new one — it only re-rolls the same ranges.

## What changes auto-apply vs only affect new drops

- There is no legacy-vs-new divergence here; every dropped Kitoko's Current uses the same mod line.
- Trade identification: the speed-penalty roll (10/12/15%) and ES/Dex rolls are visible on the item; there is no separate "version tag". A buyer reads the rolls, not a version.

## Note

This is unlike Dream Fragments, which DID have numeric changes across 0.2.0 and 0.4.0. Kitoko's Current's stability is why the article frames "current vs legacy" as roll-range only.
