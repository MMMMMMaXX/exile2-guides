# Build Usage — Kitoko's Current

Checked date: 2026-08-03
Verification status: pending-pc

Identified usage patterns for Kitoko's Current, drawn from the forum build post
(ru.pathofexile.com/forum/view-thread/26105444, which embeds the reference YouTube
video https://youtu.be/ToDEiQfo6mM) and the community thread on reddit
(r/PathOfExile2). The glove is a Lightning-hit enabler, not a generic ES glove.

## 1. Primary fit: Lightning-hit builds that want CC

The signature mod makes Lightning Hits also build Electrocution. Best on builds that
already deal Lightning damage via Hits (not DoT) and that value the stun/CC from
Electrocution:

- Lightning Spear (Amazon) — projectile lightning hits; Electrocution keeps rares/bosses
  locked.
- Ice Shot / Lightning-arrow Deadeye — hits convert or natively deal Lightning; Electrocution
  adds panic control.
- Spark (Gemling Legionnaire) — many small Lightning hits, fast Electrocution stacking.

## 2. How to use it well

- Keep damage as **Hits**, not DoT. Convert/avoid DoT so the glove's contribution applies.
- Offset the `(10-15)% reduced Attack and Cast Speed` with increased speed elsewhere
  (rings, amulet, support gems) so the net speed stays acceptable.
- Pair with shock-enabling gear if you also want the "increased damage taken" layer; the
  glove itself gives Electrocution (CC), not Shock.
- Good on a Jewelled Gloves base for the ES + Dex profile if you are Dex/Int hybrid.

## 3. Where it is weak

- Pure DoT lightning (e.g., certain ignite/storm setups that do not Hit) gets no value from
  the signature mod.
- Very speed-sensitive bleed/attack builds may feel the reduced-speed tax more.
- Not a defensive glove; it is an offensive/control glove.
