# Current vs Legacy — The Adorned

## Effect range

| Version            | Range  | Multiplier ceiling | Notes           |
| ------------------ | ------ | ------------------ | --------------- |
| Current (0.5.4)    | 0-150% | x2.5               | Raised in 0.4.0 |
| Legacy (pre-0.4.0) | 0-100% | x2.0               | Capped lower    |

A modern 150% roll is strictly stronger than any legacy 100% copy. When valuing or comparing, always check the displayed roll against the current 0-150% band.

## Corruption behaviour (unchanged)

- Both current and legacy copies drop already Corrupted; the increased-effect roll is locked at drop.
- Only a Vaal Cultivation Orb (0.4.0b+) can add extra modifiers; it does not change the base increased-effect roll.

## Targeting (unchanged)

- Both generations amplify only Corrupted Magic Jewels in passive-tree sockets in radius.
- Rare, Unique, equipment-socketed and Sinister-socketed jewels are unaffected in both.

## Mistake to avoid

Copying an old 0-100% breakpoint table undervalues a current 0.5.4 copy. Use the current breakpoint table (see effect-breakpoints.csv / the effect-breakpoints data-table section).
