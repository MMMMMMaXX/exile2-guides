# The Adorned — Build Usage

## Builds That Want The Adorned

The Adorned is a **high-budget amplifier**. It is valuable only when a build can:

1. Reach a **cluster of 2+ jewel sockets** on the passive tree (see `radius-and-placement.md`).
2. Afford to socket **Corrupted Magic Jewels** whose granted passives are strong for the build.
3. Spend the currency to **craft or buy** high-roll Corrupted Magic Jewels.

Typical homes:

- **Attribute Stacking Builds** — magic jewels that grant large attribute bonuses get multiplied, enabling extreme stat stacking. (Linked internal guide: `attribute-stacking-builds`.)
- **Aura / Defensive Stacking** builds that use magic jewels granting aura effect or resistances.
- **Specialized crit / elemental** builds that path through jewel-dense regions.

## Build Decision Framework

> **Decision:** Use The Adorned only if (jewel-socket count in radius ≥ 2) AND (budget for corrupted magic jewels ≥ cost of a single 120%+ Adorned). Otherwise skip.

This is the single most important build-level gate. A 150% Adorned with zero eligible corrupted magic jewels in radius is worthless.

## How Much Does It Add?

Per eligible Corrupted Magic Jewel, the granted passive magnitude is multiplied by `(1 + roll/100)`. See `effect-breakpoints.csv` and `magic-jewel-crafting.md` for worked numbers. With three eligible jewels at 150% roll, the effective bonus is 2.5× on each — a massive multiplier that defines high-end versions of attribute-stacking builds.

## When NOT to Use

- League-start / low-budget characters.
- Builds whose tree has no multi-socket region near their path.
- Builds that rely on Rare or Unique jewels (not amplified).
