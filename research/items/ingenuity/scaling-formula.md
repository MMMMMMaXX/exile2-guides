# Scaling Formula - Ingenuity (机巧)

Effect roll: Scaled Charm Value = Base x (1 + E/100). A +30% Fire Res charm becomes +39%/+42% at 30%/40%. Radius roll: Scaled Radius = Base x (1 + R/100), only for area charms. The two rolls are independent; prioritize the effect roll.

## Worked example
- Effect 40%, charm +30% Fire Res (4s) -> 30 x 1.40 = +42% Fire Res for 4s.
- Radius 40%, charm base 2.0 m -> 2.0 x 1.40 = 2.8 m (area charms only).
- Independent rolls: a belt can be 40% effect / 30% radius.

## Caveats
- Per-point attribute conversions (PoE2 game constants) should be confirmed in-game.
- Ingenuity radius only matters for charms with an area effect.
