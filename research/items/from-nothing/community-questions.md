# Community Questions — From Nothing

Article ID: from-nothing

## Q1 (Reddit): Does From Nothing allocate the Keystone itself?

- Current rule: No. Only passives around the bound Keystone are remotely allocated; the Keystone stays locked unless pathed.
- Answer: Path to the Keystone normally if you want it.

## Q2 (GameRant): Why are two copies with the same name priced so differently?

- Current rule: Each copy is permanently bound to a different random Keystone; price tracks Keystone relevance.
- Answer: Filter by exact Keystone on trade.

## Q3 (GamesRecon): Do I still pay passive points for allocated nodes?

- Current rule: Yes, you pay the node point; only the pathing is skipped.
- Answer: Net saving = pathing points only.

## Q4 (PoE2Wiki / general): My jewel vanished after a tree update.

- Current rule: Patch 0.2 removed some Jewel Sockets; affected jewels are reclaimed with /reclaimjewels, not lost.
- Answer: Run /reclaimjewels in town.

All four are written into the article's community-evidence section with editorial analysis and official-style answers.
