# Megalomaniac — Build Usage

## Builds That Want Megalomaniac

Megalomaniac is a **passive-point-saving** and **flexibility** unique. It fits almost any build that:

1. Has a free jewel socket (anywhere reachable).
2. Values specific Notables it cannot easily path to.
3. Wants to free passive points for damage/defense elsewhere.

Common homes:

- **Attribute Stacking Builds** — grab attribute Notables for free.
- **Builds short on points** — a 3-Notable roll saves up to ~9 points.
- **Specialized defensive setups** — allocate aura/block/evasion Notables without pathing.

## Build Decision Framework

> **Decision:** Socket Megalomaniac if (a free jewel socket exists) AND (the allocated Notables are useful for the build). A 3-Notable roll with ≥2 useful Notables almost always wins its socket. A 2-Notable roll with 0 useful Notables is a skip/sell.

## How Much Does It Add?

Value ≈ sum of passive points the allocated Notables would cost (1–3 each). A 3-Notable jewel can be worth ~6–9 points — comparable to a small passive cluster for free. See `notable-index.csv` for point-cost reference.

## When NOT to Use

- No free jewel socket and unwilling to path to one.
- The specific drop has only low-value/irrelevant Notables (sell instead).
- You need the socket for a build-critical unique (e.g., The Adorned in an amplifier build) — Limited to 1 means you cannot run both Megalomaniac and The Adorned in the same tree.
