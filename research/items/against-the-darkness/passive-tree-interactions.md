# Passive Tree Interactions — Against the Darkness

- Jewel Socket is a passive node; must be allocated and connected before socketing.
- Radius jewels project a white circle; bonuses apply to nodes inside it.
- Small vs Notable targeting is jewel-specific (Against the Darkness: one Small roll, one Notable roll).
- Default bonuses need allocation; one special roll (Against the Darkness) covers unallocated Small nodes.
- Radii can overlap; nodes in multiple radii receive each effect.
