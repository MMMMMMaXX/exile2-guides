# Build Usage — Ghostwrithe

Ghostwrithe is for characters that already live on Energy Shield and want one merged pool.

## Primary homes

1. **Stormweaver Archmage** — mana scales into ES via Archmage, so converted life just feeds the same giant pool. Pair with ES recharge + ES leech.
2. **CI-style Invoker monk** — stack ES, merge life in, gain chaos-safe-on-life without the CI keystone tradeoff. Needs disciplined ES recharge/leech.
3. **Low-life Energy Shield Templar** — merge pools, run a huge ES bar fed by auras and Corsair's flasks (still work on ES).
4. **Blink/brand ES caster** — any caster ignoring life flasks can fold life in for a simpler, larger pool.

## Hard prerequisites

- An ES sustain plan (recharge scaling + ES leech). Without it, the item is a death sentence.
- Enough total ES (life + ES) to exceed the old separated pools.

## Anti-synergy (do NOT use)

- Life-flask builds, life-leech attack builds, minion builds relying on life sustain.
- Any build that cannot reach a large ES pool.

## Attribute angle

- Vaal Regalia is Intelligence-based; invest Int for ES and ES% passives.
- The conversion does not change attribute requirements, so plan Int accordingly.
