# Community Questions — Controlled Metamorphosis

Article ID: controlled-metamorphosis

## Q1 (Reddit): Why can't I allocate a node that looks inside the radius?
- Current rule: only the annulus (band) allocates; inner circle is dead.
- Answer: place the socket so target nodes fall on the band.

## Q2 (GameRant): Does it still have a Chaos Resistance penalty?
- Current rule: no; Chaos removed in 0.4.0. Only Elemental remains.
- Answer: current 0.5.4 drops have Elemental only.

## Q3 (PoE2Wiki): What does a corrupted roll above 8 do?
- Current rule: ring value 9+ is outside 1-8 and drops the ring modifier (likely bug).
- Answer: trade only for valid 1-8 rolls.

## Q4 (YouTube): Is a bigger ring always better?
- Current rule: only if target nodes land on the band; trade price still favours larger.
- Answer: match ring size to your nodes.

All four are written into the article's community-evidence section, each with current-rule / historical-bug / reproducible framing where relevant (see troubleshooting §11.6 mapping).
