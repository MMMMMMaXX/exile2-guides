# Trade Search — Controlled Metamorphosis

Article ID: controlled-metamorphosis

## Official trade site workflow

1. Search "Controlled Metamorphosis Diamond" in the main bar.
2. Add Stat Filter for the ring size, e.g. filter "Only affects Passives in (Medium-Large) Ring" and set the numeric roll (1-8) you want.
3. Add Stat Filter for the Elemental Resistance roll (toward -5% is best).
4. Confirm the item is **Corrupted** (every copy is).
5. Confirm **Limited to: 1**.
6. Filter to the current Early Access league and online sellers.

## Value drivers

- Ring size (1-8): larger = more reach = higher trade price.
- Elemental Resistance roll: closer to -5% = better.
- Avoid copies with ring value 9+ (bug-affected, no ring).
