# Build Usage — Controlled Metamorphosis

Article ID: controlled-metamorphosis

## Decision framework

Use Controlled Metamorphosis when ALL of the following hold:

- Your useful nodes form a perimeter around a socket you can already reach.
- The rolled ring size covers those nodes (band fit).
- You can recover the -(20-5)% Elemental Resistance on gear suffixes (or run Chaos Inoculation).
- You can spare one Jewel Socket.

## Build personas (from article)

1. Wide passive-tree builds — spread-out trees with perimeter nodes.
2. Chaos Inoculation builds — CI makes the resistance penalty far easier to accept.
3. Resistance-stacked builds — already over-cap Elemental, absorb the penalty.
4. Breach pinnacle builds — pairs with Xesht farming routes.

## Build decision example

A CI spellcaster with a central socket surrounded by a perimeter of useful nodes can socket a Massive-ring copy, grab the perimeter without pathing, and pay no resistance cost thanks to CI — a high-value remote-allocation setup.
