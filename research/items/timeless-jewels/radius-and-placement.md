# Radius and Placement — Timeless Jewels

## Radius

- Both members use the Very Large radius (1500), fixed.
- Radius decides which small/notable/keystone nodes are conquered.

## Placement rules

1. Pick a normal allocated Jewel Socket whose radius covers the nodes you want conquered.
2. Preview the seed in Path of Building / client to see Notable outcomes.
3. Confirm the leader/faction name for the Keystone you need.
4. Re-verify seed + name + socket before buying.
5. Use Divine Orb to reroll seed + name if the roll does not fit.

## Variant sensitivity

- Same name, different seed -> different Notables.
- Same seed, different socket -> different conquered set.
- Verify all three fields (seed, name, socket) every time; never reuse an old guide's seed blindly.
