# Alternatives — Timeless Jewels

- Normal / Magic / Rare jewel: own modifiers, no conquest. Use when you do NOT want to transform radius passives.
- Time-Lost Jewel: different base, different modifier pool — NOT a Timeless member; do not confuse.
- Other Unique jewels: The Adorned (corrupted Magic amp), From Nothing (remote Keystone), Controlled Metamorphosis (ring remote allocation), Megalomaniac (Random Notables), Voices (Sinister Sockets) — different mechanics, no radius conquest.
- If you only need an existing tree Keystone, a Timeless transformation may be unnecessary; reserve it for converted/themed Keystone + Notable sets.

Pick the alternative that matches the need: plain radius bonus vs themed conquest.
