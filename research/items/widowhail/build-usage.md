# Widowhail — Build Usage Research

## Core principle
Widowhail is a quiver-delivery system. It only pays off when the build funnels value through the quiver slot AND supplies a strong quiver. Each listed home has a hard prerequisite (the quiver) that must be met before the bow pays off.

## Realistic homes

### 1. Ice Shot Deadeye
- Natural home: Deadeye rewards projectile count; a quiver stacked with added cold/physical damage, attack speed and +projectile-skill levels gets multiplied several times.
- Target: 230%+ Widowhail + quiver with +2 projectile skill levels and high added damage.
- Related slug (allowlist): `ice-shot-deadeye` (build), `ice-shot` (skill).

### 2. Spark / converted-spark casters (Blood Mage, Stormweaver)
- Widowhail amplifies a quiver granting +projectile skill levels and projectile speed; the multiplied projectile scaling feeds Projectile Acceleration and Spark's multi-hit damage.
- Budget variants clear early maps for a few dozen Exalted Orbs.
- Evidence: official forum Spark Infernalist thread (source-ledger #6).

### 3. Lightning Arrow / Lightning Rod Ranger leveling
- From Act 2, Widowhail + frequently-upgraded Rare quiver is one of the strongest leveling bows (multiply added damage & attack speed as you out-level each quiver).
- Evidence: MaxRoll leveling-uniques analysis (source-ledger #5).

### 4. Poisonous Concoction Pathfinder
- High-roll Widowhail + quiver with +2 Levels of all Projectile Skills, accuracy and attack speed spikes poison DPS via Master Fletching and the quiver multiplier.
- Evidence: community forum PC setup thread (source-ledger #7).

## Hard prerequisite per build
- Every build above requires a purpose-built quiver. Copying a streamer's quiver onto a different ascendancy/skill wastes the multiplier because damage tags / conversions differ.
