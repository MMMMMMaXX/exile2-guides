# 全站壳层

> 本节更新时间：2026-07-27 01:52（Asia/Shanghai）

## Header

`AppShell` 为每个公开页面提供统一 Header。品牌链接回到当前语言首页；英文与简体中文入口均为
可键盘访问的真实链接，并明确当前语言。桌面端 Header 保持 72px 高度；窄屏时主导航使用可访问的
折叠菜单。

根据用户在 2026-07-27 01:32 的明确产品决定，所有分类始终出现在 Header，且每项都跳转到对应
语言的静态分类路由。没有已发布内容时，页面展示真实的准备状态并使用 `noindex, follow`；不展示
草稿、样例或虚构卡片。Search 与法律入口仍等待各自正式任务完成后启用。

## Footer

> 本节更新时间：2026-07-27 01:52（Asia/Shanghai）

Footer 始终显示：

- 品牌简介；
- 明确的非官方、未获 Grinding Gear Games 认可声明；
- 分类名称；
- About、Contact 和全部 PRD 要求的法律信息；
- 当前年份版权信息。

分类页和信息/法律页均使用当前语言的真实静态链接。Contact 页在公开联系邮箱配置前只说明真实状态，
不使用会误导用户的占位邮箱。没有社交账号前不显示空社交链接；Header 和 Footer 中也不允许出现 AI、
登录或 Pricing 入口。
