# LAUNCH-010 原创视觉与页面内容验收

## 1. 当前结论与范围

> 本节更新时间：2026-07-27 21:28（Asia/Shanghai）

当前公开攻略内容为 0；12 个模板和 22 个真实研究草稿均保持 `draft`，因此本批次不向任何生产路由加入文章图、游戏截图、Logo、角色立绘或第三方素材。这样既不把未核验事实通过图片暗示为已确认，也不引入无法证明授权范围的资源。

允许在后续已核验内容中使用的首发视觉只限以下两类：

1. 由 StratLore/Max 从零创作的设计资产，例如 CSS 图形、原创 SVG、原创插画或自制示意图。
2. 权利人明确书面授权、且授权范围覆盖 `poe2.stratlore.com` 公开展示的素材；授权记录必须保存在本台账，并能说明署名、期限、地域、改编和商业展示限制。

不因“可在官方公告、游戏客户端、Steam、Wiki、视频或社交媒体看到”而推定可再发布。GGG 游戏画面、艺术图、商标、公告配图、第三方截图、构筑工具图和社区图片，在没有对应许可记录前一律不得加入仓库或页面。未请求也未生成 AI 图片；如将来决定使用，仍需先完成其许可、品牌相似性、事实准确性和读者披露评估。

## 2. 视觉资产台账

> 本节更新时间：2026-07-27 21:28（Asia/Shanghai）

填写规则：

- `资产 ID` 一经使用不可重用；源文件、导出文件和权利证明使用相同 ID 便于追溯。
- 授权证据不得只写“已同意”；应记录授权邮件/合同/原始文件的位置、许可文本、确认日期和有效期。私人凭据不得提交到仓库，应在受控位置留存其引用编号。
- Alt 只陈述画面中可见的内容；不写掉落、强度、机制或版本结论，除非该事实已在相同版本下核验并在正文有来源。
- 图片必须满足既有图片契约：明确宽高、响应式 `srcset`/`sizes`、非首屏延迟加载、格式与体积门禁；不能用装饰图替代正文解释。

## 3. 原创视觉实施准则

> 本节更新时间：2026-07-27 21:28（Asia/Shanghai）

首个可发布内容如确有视觉需求，优先制作不依赖游戏官方资产的原创信息图：版本范围标记、核验流程、阅读路径或由已核验数据生成的简洁比较图。视觉实现应复用现有设计 Token，保持深色背景、充分文字对比和可读字号；图表必须在图下提供同等信息的文字或表格，避免把关键事实只放在图片里。

每项资产合并前依次完成：事实审核 → 权利审核 → 双语 Alt 审核 → `npm run quality` → 在下列四个宽度抽查。素材本身不是发布依据：关联文章仍须分别满足来源、游戏内核验、双语审核和 `published` 状态门禁。
