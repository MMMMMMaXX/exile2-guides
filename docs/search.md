# Search 页面说明

> 本节更新时间：2026-07-27 02:10（Asia/Shanghai）

构建阶段为 English 与简体中文分别输出 `search-index/<locale>.json`，并提供相同的已发布内容索引给浏览器本地搜索。索引只含标题、摘要、标签、目录标题、分类和规范路径，不含草稿或完整正文。搜索按当前语言隔离，匹配标题、摘要、标签、目录标题与分类；默认显示最多 20 条并可继续加载。关键词仅存在 URL query 与浏览器内存，搜索页始终 `noindex, follow`，不进入 Sitemap。
