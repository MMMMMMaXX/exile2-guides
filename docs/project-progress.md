## 必须遵守的更新说明

> 本节更新时间：2026-07-26 23:13（Asia/Shanghai）

本文件是项目进度的唯一台账。任何 Codex 会话或人工开发者在本仓库工作时都必须：

1. 开始前读取本文件和 `AGENTS.md`。
2. 正式任务开始时，将任务状态改为“进行中”，填写开始时间。
3. 正式任务结束时，填写完成时间、交付结果、验证结果和下一步。
4. 计划外修复、规范调整、工具建设写入“任务外事项表”。
5. 每次独立工作请求结束前，在“会话时间线”末尾追加一行。
6. 修改任何表格时，同时更新表格所属章节和文档顶部的绝对时间。
7. 所有时间使用 `Asia/Shanghai`，格式为 `YYYY-MM-DD HH:mm`。
8. 历史时间没有可靠日志时写“具体时间未保留”，不得补造分钟。
9. 未通过该任务所需验证时，不得把状态标记为“已完成”。

状态只使用：

- `未开始`：尚未进入实现。
- `进行中`：已经开始，但交付或验证尚未完成。
- `已完成`：实现和该任务要求的验证均完成。
- `受阻`：存在明确外部阻塞，并已记录原因。

会话编号按 `SESSION-001` 递增。这里的“会话”指一次独立用户工作请求；同一 Codex
线程中的不同请求也分别记录。
