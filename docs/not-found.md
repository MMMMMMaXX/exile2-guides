# 404 页面说明

> 本节更新时间：2026-07-27 11:54（Asia/Shanghai）

## 静态托管行为

> 本节更新时间：2026-07-27 11:54（Asia/Shanghai）

`public/404.html` 会进入生产输出根目录。静态托管平台必须将未知 URL 以 HTTP `404` 状态返回此文件，而不是回退到首页或 SPA 空壳。页面是独立完整 HTML，不依赖 JavaScript；提供英文首页、搜索与主要分类的恢复入口。React Router 的通配路由只用于客户端已加载后的同等恢复界面，不能替代主机的 HTTP 状态码。

## 索引边界

> 本节更新时间：2026-07-27 11:54（Asia/Shanghai）

静态错误文档和通配路由均输出 `noindex, nofollow`。`404.html` 不属于公共预渲染路径，因此不会成为内容消费者、搜索索引或后续 Sitemap 的输入；TASK-019 生成 Sitemap 时必须继续排除它。

## 构建门禁

> 本节更新时间：2026-07-27 11:54（Asia/Shanghai）

构建结束时会读取生产输出的 `404.html`，校验标题、描述、完整 `main` 内容和 robots 指令。缺失或不符合 noindex 要求会使构建失败。
