# 首页

> 本节更新时间：2026-07-27 01:22（Asia/Shanghai）

## URL 与预渲染

根路径 `/` 的静态 HTML 保留完整语言选择作为无脚本回退。真实浏览器首次加载时读取第一首选语言：
简体中文相关标签进入 `/zh-cn/`，其他或未知语言进入 `/en/`，因此加载完成后的地址栏始终包含语言
路径。`/en/` 与 `/zh-cn/` 是独立公开首页，已加入静态预渲染清单，并各自输出完整标题、描述、
正文及正确的 HTML `lang`。

右上角英文与简体中文入口可直接切换两个首页，Logo 返回当前语言首页。详情页按 `contentId` 保持
同一内容的切换策略仍由 TASK-020 完成，在此之前语言入口只使用始终存在的语言首页，避免生成 404。
